How it works

A simple workflow from upload to review.

Fieldnote focuses on the steps security teams repeat every day, without requiring a complicated workflow to get started.

1

Upload evidence

Officers add photos or videos, confirm the captured time, and enter supporting details such as notes or an incident number.

2

Store it privately

Files are saved inside a restricted workspace designed for internal evidence handling rather than public sharing.

3

Review and manage

Supervisors or administrators can review evidence in the catalog, retrieve records, and support documentation workflows.

FAQ

Common client questions.

Use this section to answer the practical questions prospective clients are likely to ask during early conversations.

What is Fieldnote designed for?

Fieldnote helps security teams organize photo, video, and incident-report files in a restricted workspace, recording the uploader and other file metadata.

Can clients request a pilot first?

Yes. Organizations can request a scoped pilot to discuss evaluation goals, duration, team size, and deployment requirements before agreeing to any terms.

Does the Fieldnote license include backend support?

Backend development, server-side infrastructure, database maintenance, and ongoing security maintenance are not included by default. A qualified backend provider must be separately engaged and scoped.

Are submissions automatically stored by this website?

Not by default. The page is prepared for either mailto-based lead capture or connection to a secure form endpoint. This avoids implying back-end handling that has not been configured yet.
